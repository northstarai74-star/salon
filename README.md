# Lumière Hair & Beauty Studio

A premium, editorial marketing and booking site for a luxury hair and beauty salon, built with Next.js (App Router), TypeScript, and Tailwind CSS v4.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Project Structure

- `src/app` — routes: homepage, `/booking`, `/stylists/[slug]`, legal pages, SEO files (`robots.ts`, `sitemap.ts`, `opengraph-image.tsx`, `icon.tsx`).
- `src/components` — presentational and interactive UI (Navbar, Hero, Gallery, BeforeAfterSlider, TestimonialCarousel, `booking/` widget, etc).
- `src/lib/data.ts`, `src/lib/salon.ts` — all editorial content (services, stylists, testimonials, gallery, salon info/hours). Edit these to update copy without touching components.
- `src/lib/booking/` — the booking abstraction (see below).
- `public/images` — placeholder photography (SVG). See "Photography" below.

## Photography

Real salon photography is not available in this environment, so `public/images` is populated with elegant, on-brand SVG placeholders generated by `scripts/generate-images.mjs`. Each file uses the same descriptive filename a real photo would (`hero-salon.svg`, `service-highlights-balayage.svg`, `stylist-01.svg`, etc).

**Before launch:** replace these files 1:1 with real photography (same filenames, or update the `image` paths in `src/lib/data.ts`). To regenerate placeholders after editing the generator, run:

```bash
node scripts/generate-images.mjs
```

## Booking Architecture

The booking UI never talks to a scheduling backend directly — it talks to the `BookingProvider` interface defined in `src/lib/booking/types.ts`:

```ts
interface BookingProvider {
  getServices(): Promise<BookingService[]>;
  getStylists(): Promise<BookingStylist[]>;
  getAvailability(query: AvailabilityQuery): Promise<string[]>;
  createAppointment(request: AppointmentRequest): Promise<AppointmentConfirmation>;
}
```

`src/lib/booking/localProvider.ts` is a local, in-memory implementation used until a real backend is connected. `src/lib/booking/index.ts` is the single swap point — replace `localBookingProvider` there with an adapter for Fresha, Mindbody, Vagaro, Booksy, or a custom API, implementing the same interface. No component code needs to change.

The booking experience itself (`src/components/booking/BookingWidget.tsx`) is used in three places: the homepage `#booking` section, a modal reachable from every "Book Appointment" CTA (`BookingModalProvider`), and the dedicated `/booking` page.

## SEO

- `BeautySalon` JSON-LD structured data (`src/components/StructuredData.tsx`), including services and opening hours.
- Per-page metadata, Open Graph, and canonical URLs via the Next.js Metadata API.
- Dynamically generated OG image and favicon (`src/app/opengraph-image.tsx`, `src/app/icon.tsx`).
- `robots.ts` and `sitemap.ts`.
